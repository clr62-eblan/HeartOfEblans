- Захват Квадроберов

- Чикен-Бекония: К маяку вселенной, ANEMONE, холода ветра, Светлая сторона

- Братишкин и Блогема

- Собаки Бустера
- Джампер пройден

- Немного изменена ветка экономики

- Фокус "Приютить выдворенных Лайкеров" изменён
